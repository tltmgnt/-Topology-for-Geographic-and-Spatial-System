# Project working agreement

Treat clear implementation and failure reports as instructions to investigate and
complete authorized work. Read the current contracts before changing behavior.
Run unit tests and installed-package workflows after relevant changes. Preserve
explicit missingness, fail-closed input validation and the separation between
bundle consistency and requirement satisfaction. Do not change expected outcomes
just to make CI pass. Keep real network data private; only synthetic fixtures may
be uploaded by CI. Do not imply geographic completeness, safety certification,
source authenticity or external execution from a passing graph analysis.
